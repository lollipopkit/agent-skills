# agent-skills

Skills for coding agents (Claude Code, Codex, and others that read `SKILL.md`).

## Install

```bash
npx skills add lollipopkit/agent-skills
```

## Skills

| Skill | What it is for |
|---|---|
| [codex-clean-history](codex-clean-history/SKILL.md) | Preview and clean Codex logs, sessions and input history, keeping memories and configuration. |
| [glitchtip-api](glitchtip-api/SKILL.md) | GlitchTip through its REST API: filter an issue's events by release, IP or time, see which releases still hit it, sweep issues by stack frame, resolve in a release. |
| [handoff](handoff/SKILL.md) | Concise, evidence-based handoff notes for another coding agent. |
| [linked-doc](linked-doc/SKILL.md) | An evolving, linked documentation library: wikis, ADRs, design and research notes, release notes, decision logs. |
| [trailbase](trailbase/SKILL.md) | TrailBase: install and run, config and migrations, Record APIs, auth, SDKs, WASM endpoints. |
| [use-fllib](use-fllib/SKILL.md) | fl_lib stores, widgets, utils and extensions in Flutter apps. |
